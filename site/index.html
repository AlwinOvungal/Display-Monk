Keys & command line

Brightness keys follow your pointer. Script the rest with displaymonk.

F1F2
$ displaymonk brightness 60 -d external
$ displaymonk input hdmi1
✓ External Display → HDMI 1

Gentle by design. Display Monk does nothing while idle, spaces monitor writes at least 100 ms apart, and undoes a refresh-rate or rotation change unless you confirm it within 15 seconds.

Uses about 0% CPU with the menu closed.

Get Display Monk for your Mac.

One small app for Apple silicon and Intel Macs. It sits in your menu bar, has no Dock icon, and stays out of the way.

Version · · released

Install with one command, with no security prompt. Paste it into Terminal:

curl -fsSL https://alwinovungal.github.io/Display-Monk/install.sh | bash
Download DisplayMonk.dmg

Prefer a zip? Download DisplayMonk.zip

Downloaded the dmg and macOS blocks it? Clear it from Terminal:

xattr -dr com.apple.quarantine "/Applications/Display Monk.app"

Install in three steps

  1. Paste the install command into Terminal. It puts Display Monk in Applications and opens it, and it appears in your menu bar.
  2. Or use DisplayMonk.dmg: drag Display Monk into Applications and open it. The app isn't signed with an Apple Developer ID yet, so macOS blocks that first launch. Click Done, then go to System Settings › Privacy & Security and click Open Anyway. After that, the app updates itself.
  3. Optional: turn on the brightness and volume key options. Brightness keys control the display under your pointer, volume keys the monitor you picked as sound output. macOS asks for Accessibility access then.

Questions

Good to know.

Something else on your mind? Open an issue on GitHub.

Is Display Monk really free?

Yes. Display Monk is free and open source under the MIT license. There is no paid tier, trial or account.

Will it work with my monitor?

Most monitors that support DDC/CI work over USB-C, Thunderbolt and DisplayPort. Some HDMI ports on Apple silicon Macs and some docks block DDC. In that case Display Monk falls back to software dimming, which works on any screen.

Can my displays share one brightness?

Yes. Turn on Sync Brightness at the top of the menu, and moving any display's slider moves them all. The brightness keys work too. Turning it off leaves each display where it is. Sync matches the percentage, not the light output, so two different panels can look a little different at the same level.

Why does it ask for Accessibility access?

Only if you turn on the brightness or volume key options. macOS needs it so Display Monk can catch those keys and send them to the right display. After updating the app, remove Display Monk from the Accessibility list with – and add it again with +, because macOS stops trusting the new copy.

Are my changes permanent?

Brightness, contrast, volume and input are ordinary monitor settings, so the monitor keeps them. Software dimming ends when you quit the app. HiDPI also lasts only while the app runs, unless you choose Make HiDPI Permanent, which you can remove from the same menu.

How do I uninstall it?

Quit Display Monk from its menu, then drag it from Applications to the Trash. If you made HiDPI permanent, remove that first from the display's … menu.
